# Project instructions

This is an existing Laravel ERP application.

## Critical rules

- Preserve all existing behaviour.
- Preserve the current UI/UX exactly.
- Do not redesign pages.
- Do not change routes or API formats.
- Do not change database structures without approval.
- Do not install packages without approval.
- Do not change BOM or raw-material formulas.
- Preserve the separate 3D-carton and syrup-box calculations.
- Preserve decimal precision and rounding.
- Do not modify unrelated files.
- Run tests after every change.
- Start every task with a read-only analysis.
